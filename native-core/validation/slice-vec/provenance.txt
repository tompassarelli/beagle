refreshing against a moved fram — main.c is ordinal-addressed
  main.c is hand-written and calls the probe leaves as native_m0_fn_N by their
  position in the lowered program, so a fram defn that lowers ahead of the
  probe module renumbers every one of them and main.c stops compiling. The
  repair is mechanical and must be part of the same refresh: read the new
  ordinals out of report.txt's `lowered fn_N <name>` lines and rewrite main.c's
  calls and its header map. Type ordinals (native_m0_type_N) are assigned in a
  separate sequence and do not have to move with the functions.

layout rule — a vector value is a REFERENCE to its header
  A (Vec T) value is one 8-byte handle on a shim-owned
  native_vec { void *elements; int64_t length; int64_t capacity; } allocated in
  a region beside its element storage. LayoutShapeV0/VectorShapeV0 keeps
  describing the ELEMENT storage (element-type + stride), never the value.
  Consequences:
    - a (Vec T) record field is 8 bytes at 8-byte alignment for every T, so
      closed-layouts closes for (Vec Record) without measuring the element;
      t/TermStore, with ten vector-shaped fields, is 104 bytes and every such
      field is a reference (it was a 24-byte inline descriptor per field before).
    - the C projection is 'typedef native_vec *native_m0_type_N;'.
    - region-lifetime law (thread 019fbd6c ratification) applies unchanged: the
      handle may not outlive the region holding the header and its elements.
      Vacuous under the single slice arena; load-bearing once regions nest.
    - conj is persistent under arbitrary one-thread aliasing: native_vec_push
      writes only at the shared storage watermark and returns a fresh header.
      A sibling append after the watermark advances copies before writing, as
      do full or foreign buffers. A linear accumulation path remains amortized
      O(1); concurrent appends over shared storage require an external lock.

token discipline
  A function whose lowered body allocates gains the arena-allocate effect, the
  slice arena region, and the arena-allocate capability. Those tokens are
  affine, so the discharge is attached, after the CFG is known, to the first
  allocating instruction of a block no entry->exit path can bypass; a body with
  no such block is refused as TODO-NATIVE-CONDITIONAL-ALLOCATION rather than
  leaking a token.

real-function evidence (report.txt)
  fram.store/valid-handle? reads (Vec Record) fields of t/TermStore through
  count and lowers to nine blocks. operation-range-bounds reads the transaction
  and operation vectors through count/nth and returns [start end]; its remaining
  TODO-NATIVE-CALLEE is first-transaction-after, whose loop is outside this
  slice. No real fram count/nth/conj site is a C-callable leaf in this
  vocabulary, which is why the C-callable entry points live in vec_probe.bclj
  over the same fram.types records.
