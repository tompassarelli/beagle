# beagle cheatsheet

What the language can do, with verified examples. Generated by
`bin/beagle-cheatsheet` from beagle-lib/private/cheatsheet.rkt; every
example is parse+type-checked under its named target, so nothing here is stale.

Native Core files use bare `#lang beagle` on `.bgl`. Hosted targets use
`#lang beagle/clj` on `.bclj`, `#lang beagle/js` on `.bjs`, or
`#lang beagle/nix` on `.bnix`. Then write `(ns ...)` and ordinary forms.
For signatures, fields, and the full form set, query the compiler
(`bin/beagle sig|fields|syntax`, or `bin/beagle` for all commands);
for the target list itself, `bin/beagle langs`.

## Types

### defrecord
Target: `clj`

Product type with typed fields; generates a constructor and accessors.

```clojure
(defrecord Point
  [x Int
   y Int])
```

### defunion + match
Target: `clj`

Sum type over records. `match` must cover every constructor; a missing constructor is a compile error.

```clojure
(defrecord Circle [r Int])
(defrecord Square [side Int])
(defunion Shape Circle Square)
(defn area [s Shape] Int
  (match s [(Circle r) r] [(Square side) side]))
```

### defenum
Target: `clj`

Enumeration of named constants.

```clojure
(defenum Color Red Green Blue)
```

### typed binding pairs
Target: `clj`

A typed binding vector alternates `binding-form Type` — strict pairs all the way through. Every binder carries an authored type; an omitted one is a rejection naming that binder. Sequential and associative destructures may occupy `binding-form`; the whole pattern is ONE binder, and its complete incoming aggregate is what the type describes, so projected names need no annotations of their own. More than one binding in a vector always breaks one complete binding per line, at every binding site and with no width threshold; any single binding stays inline, including a refinement. Record fields take the same pair law, and metadata flattened out of its declaration is rejected. Executable signatures place their mandatory return on the same line as the parameter vector's closing `]`; a type-level function signature is `(Fn [ParamType ...] ReturnType)`. A per-binding constraint is a refinement type expression, `(Int where positive?)`; a cross-parameter `(where ...)` clause always occupies its own line after the return type. The legacy grouped spelling is still read while the corpus migrates, but canonical writers emit only the pair form.

```clojure
(defrecord Size
  [w Int
   h Int])
(defn scaled-area
  [{:keys [w h]} Size
   factor Int] Int
  (* factor (* w h)))
```

### forall type variables
Target: `clj`

Explicit rank-1 polymorphism uses `(forall [T ...] Type)`. Names in the vector are rigid type variables inside `Type`; a bounded variable is written `(T <: Bound)`.

```clojure
(declare-extern host/id (forall [T] (Fn [T] T)))
(def enemy-id String (host/id "slime"))
```


## Types / contracts

### defscalar :where
Target: `clj`

Refinement contract: a base type narrowed by predicates. Literal violations are caught statically; non-literal values get a runtime guard emitted per target (nix `assert`, clj `:pre`, js `throw`).

```clojure
(defscalar Percentage Int :where (>= 0) (<= 100))
(def half Percentage (->Percentage 50))
```

## Functions

### defn
Target: `clj`

Function with typed params and return. Params are a bracket vector.

```clojure
(defn add
  [x Int
   y Int] Int
  (+ x y))
```


## Control flow

### let / loop / recur / cond
Target: `clj`

Standard control flow; bindings use bracket vectors.

```clojure
(defn sum-to [n Int] Int
  (loop [i Int 0
         acc Int 0]
    (cond [(> i n) acc]
          [:else (recur (+ i 1) (+ acc i))])))
```


## Macros

### defmacro + quasiquote
Target: `clj`

Hygienic macros. Quasiquote `` ` ``, unquote `~`, splice `~@`. Free references resolve at the macro's definition site (mode-2 hygiene). Structural declaration macros use `(syntax-error-at original-input index message ...)` from `map-indexed` to point at one exact caller form; indices are zero-based over logical elements.

```clojure
(defmacro twice [x] `(do ~x ~x))
```


## Interop

### declare-extern
Target: `clj`

Declare a host function/value with a type so typed code can call into the target runtime.

```clojure
(declare-extern host/now (Fn [] Int))
```

### direct JavaScript interop
Target: `js`

Direct properties and member calls preserve their receiver. Use `.-member` for a static property, `set!` to write it, and bare `new` to construct a host value.

```clojure
(declare-extern [js/Ctor obj] Any)
(def static-value Any (.-raw_name obj))
(def called Any (.run obj 1))
(def assigned Any (set! (.-raw_name obj) 2))
(def created Any (new js/Ctor))
```

### ^:async + await
Target: `js`

Mark a function `^:async` when it uses bare `await`; its declared return remains a `Promise` of the awaited value type.

```clojure
(declare-extern load (Fn [] (Promise Int)))
(defn ^:async load-value [] (Promise Int)
  (await (load)))
```

### this-as
Target: `js`

Bind JavaScript `this` explicitly for one expression; the form is available on the JavaScript target only.

```clojure
(defn capture-this [] Any
  (this-as self self))
```

### .. receiver chain
Target: `js`

Thread one JavaScript receiver through member-call steps without losing method receiver semantics.

```clojure
(declare-extern factory (Fn [] Any))
(def chained Any (.. (factory) (child) (value)))
```
