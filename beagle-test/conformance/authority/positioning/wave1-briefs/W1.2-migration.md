# W1.2 — Migrate the legacy compiler dispatch before deleting it

## Outcome

Remove the retired hard-coded list dispatcher only after every live fallback
caller has moved to the compile-time combiner/call path. Preserve malformed
form diagnostics, ordinary unknown-head calls, hosted Clojure compilation,
JVM/nominal type compatibility, and emitted JavaScript field identity during
the migration. This is a migration-first order; the blocked lane proved that
the 89 callers are load-bearing.

## Evidence and starting point

The `legacy-dispatch` lane reports no commit beyond the shared integration
history and is clean at `23214318`. The blocked report records 89 live direct
callers, including the hosted-Clojure/JVM fallback. The clean source authority
for this order is Beagle `96e5d08b`; the integration candidate is
`8fd36b52`. Do not inherit uncommitted lane edits.

The candidate keeps the same total of 89 direct `parse-list-form*` calls but
redistributes them as the combiner registry grew. The exact inventories are
below; every number is a direct call site, not a comment or the dispatcher
definition.

## File boundary

The worker may edit only the dispatch and its named callers in
`beagle:beagle-lib/private/parse.rkt`, the named JavaScript record-field
compatibility block in `beagle:beagle-lib/private/emit-js.rkt`, and focused
parser/checker/emitter/self-host fixtures that prove those contracts. The
worker may not change unrelated AST representation, scope-resolution rules,
target emitters, tier infrastructure, or hosted-dispatch shell routing.

## Migration order and lowest-layer verification

1. **Freeze the characterization surface.** Re-run the exact inventory with
   `git grep` at both commits and query the private dispatcher with the
   repository caller tool. Add no source change until the 89-line manifest,
   the malformed-known-form cases, unknown-head call cases, and the
   hosted-Clojure/JVM type-name cases are recorded. The deterministic check is
   the caller census plus the focused parser tests.

2. **Migrate the 24 core-combiner fallbacks.** For every candidate line in the
   first group, give the registered handler an explicit malformed-shape
   result. A handler may use the canonical ordinary call-form path only for a
   shape that was previously an ordinary call; it may not silently fall
   through to a second form matcher. After each family batch, run the lowest
   layer: `raco test beagle-test/tests/parse.rkt` and its exact malformed-form
   fixtures, then repeat the 24-line census.

3. **Migrate declarations and control forms.** Move the 26 candidate sites
   in the second group, including `defn`/`defn-`, removed-form diagnostics,
   threading, `get`, and the assertion/error forms. Preserve the existing
   error kind and suggestion text. Verify with the parser tests first, then
   the checker tests that consume the resulting typed IR; do not use the full
   tier as a substitute for either proof.

4. **Migrate module, target, and JavaScript forms.** Move the 31 module/target
   sites and 7 JavaScript sites. Finish the unknown-head path by routing it
   through the ordinary call-form constructor, not a renamed legacy matcher.
   Verify parser output and target-specific focused emit tests for Nix,
   Clojure, and JavaScript. The exact lower-level byte check is the existing
   emitter golden suite.

5. **Migrate imported record names in the JS emitter.** Replace the
   `with-legacy-type-names` seed with the structural provider/name table used
   by current module interfaces. Keep local record fields, imported field
   order, refer lists, and provider identity as separate facts. Verify first
   with `beagle-test/tests/emit-js.rkt` and the qualified-reference JS golden;
   then run the cross-target emitter checks.

6. **Remove the old dispatch only after the census reaches zero.** Delete the
   `parse-list-form*` matcher, its `parse-list-form` wrapper if no caller
   remains, the direct tests of the retired dispatch arms, and
   `with-legacy-type-names` with its direct tests. Run parser, checker, all
   active emitters, self-host remint, and the exact negative fixtures. The
   final full active tier is an integration confirmation, not the seam proof.

## Landing bar

Land only when the 89-caller census is zero, the focused parser/checker/
emitter checks and self-host remint pass on the same commit, hosted-Clojure
and JVM/nominal compatibility cases have exact expected output, and the
tracked-tree absence search below is empty. Commit only the enumerated source
and focused-test paths, land through `safe-push --to main`, fast-forward
`beagle:main`, and reap the worker lane and branch. Remote CI is asynchronous
and does not gate the landing.

## Rollback

Keep the old dispatcher intact until the final deletion commit. If any parity,
diagnostic, hosted-Clojure, or emitter check fails, stop that migration batch,
retain the previous commit as the runnable path, and revert only the failed
batch. If failure appears after deletion, revert the deletion commit as one
unit and re-run the seam checks before attempting the next batch. Do not reset
or clean the existing dirty `scaffold-guard` lane while recovering this lane.

## Final deletion and absence proof

After every caller has migrated, delete the complete legacy dispatch surface,
its direct tests, and the JavaScript `with-legacy-type-names` compatibility
surface. Then run a tracked-tree search from the landed Beagle checkout for
`parse-list-form*`, `parse-list-form`, `with-legacy-type-names`, and the exact
retired dispatch error/helper names. Every result must be absent; only then
run the owning focused gate one final time.
