so this order is migration-first; it does not delete the helper at the start.

## Migration contract and order

1. **Define the replacement contract first.** Add one private structured
   projection in the AST layer, named `beagle-syntax->structured-value` in
   Racket and `beagle-syntax->structured-value!` in self-host. It must retain a
   `structural-name` for identifiers, recurse through lists/vectors/quotes/
   unquotes, and preserve the existing bracket tag. It is a semantic value
   view, not a source-location view; callers that need spans/scopes/origin must
   continue using the syntax accessors. Verify the contract at the lowest
   layer with the syntax membrane tests, including qualifier, leaf, provider,
   quote, and unquote cases.

2. **Migrate macro evaluation.** Replace the import and `macro-datum` path in
   `macro-eval.rkt:17,56` with the structured projection. Update equality,
   truthiness, numeric checks, and syntax-match comparisons so StructuralName
   values are never rendered to symbols. Verify with the focused macro-eval
   and syntax-match tests before touching expansion orchestration.

3. **Migrate macro orchestration and raw-datum boundaries.** In
   `macros.rkt:16,256,391,514,530,546`, use syntax-list children and the
   identifier name accessor for macro-head detection and names; use the
   structured view only for trace/debug payloads. First census callers of
   `expand-macro` and `expand-fully`, migrate raw-datum callers to the syntax
   input contract, then remove their raw-output conversion branches. Verify
   with macro hygiene, macro expansion diagnostics, and exact trace fixtures.

4. **Migrate parser and scope diagnostics.** Replace the three candidate
   parser uses at `parse.rkt:164,2118,2160` with explicit source-diagnostic
   rendering plus syntax accessors; do not use a generic symbol projection for
   blame. Replace `scope-resolve.rkt:33` with a direct structural-head/
   children walk. The lowest checks are the parser diagnostic tests and the
   scope-resolution spike tests, followed by the macro-source error fixtures.

5. **Mirror the contract in self-host.** Migrate the six seed AST uses, the
   seed parse use, the seven source AST uses, and the source parse use listed
   above. Run the self-host syntax-match fixture and the repository remint/
   parity check after each Racket/seed/source batch. A Racket-only green test
   is insufficient.

6. **Migrate the direct syntax test.** Replace
   `beagle-test/tests/syntax.rkt:450` with assertions over
   `syntax-ident-name` and its qualifier/leaf/provider fields. Keep the test's
   source-span and quote/unquote cases. Run the syntax suite and AST JSON gate
   at this step.

7. **Delete only after the caller census reaches zero.** Remove the old
   implementation, imports, exports, self-host mirrors, comments, and direct
   tests. Do not leave a compatibility alias or an error-only tombstone.
   Run the syntax, macro, parser/checker, self-host remint, AST JSON, and
   active compiler gates on the deletion commit.

## Landing bar

Land only when the exact 35-occurrence candidate census is zero for the
removed helper, all structured-value/macro/scope/self-host focused checks pass
on the same commit, AST JSON output is unchanged where the contract requires
it, and the final tracked-tree search is empty. Commit only the listed source
and direct-test paths, land through `safe-push --to main`, fast-forward
`beagle:main`, and reap the lane and branch. Remote CI is asynchronous.

## Rollback

Keep the old helper available until each migration batch has passed its own
focused check. On a failure, revert only the failed batch and retain the old
adapter for the next attempt. If the final deletion fails parity, revert the
single deletion commit and resume from the last green structured-value batch;
do not reset or clean another lane's work.

## Final deletion and absence proof

After all 35 callers have migrated, delete the complete lossy helper surface,
including its exports, direct tests, Racket implementation, and self-host
mirrors. Then run a tracked-tree search for the exact tokens
`beagle-syntax->datum` and `beagle-syntax->datum!` across the Beagle tree. The
search must return no result, followed by one final owning syntax/macro gate.
