## Migration order and lowest-layer verification

1. **Re-census the bridge.** On a clean lane, run the caller query and tracked
   search for the retired symbol accessor plus the forward and reverse
   structural-name bridges. Classify each result as definition, export, guard,
   or live caller. The lowest check is the zero/nonzero guard result plus the
   exact caller list above.

2. **Migrate the live checker caller.** Replace
   `check.rkt:24-28` and the dependent reference-table lookup path with the
   canonical `structural-name` key. The checker must no longer manufacture a
   `qualified-ref` solely to probe a StructuralName-backed table; provider
   identity, qualifier, leaf, and unbound fallback behavior must remain
   identical. Run the focused checker/definition-inference tests first, then
   the qualified-reference parse and emit tests.

3. **Prove the representation remains live.** Run the qualified-reference
   parser tests, JavaScript emitter golden, branch-corpus identity and rename
   gates, and the scope-resolution tests. These must demonstrate that
   `qualified-ref` construction/accessors still serve real authored and
   resolved references. A nonzero bridge search is not itself proof of a live
   representation; the named tests are.

4. **Close the guard boundary.** Extend the scaffold guard to search all three
   retired names: the symbol accessor and both structural-name bridges. Run the
   guard from the clean lane. Do not use the current dirty lane patch as the
   implementation; it is an uncommitted worker artifact.

5. **Delete the bridge surface.** Remove both definitions, their exports,
   direct bridge tests, and any comments/error-only residue. Keep the
   `qualified-ref` struct and all live field accessors. Run the guard, checker,
   parser/emitter tests, self-host remint, and Store code-as-facts checks after
   deletion.

## Landing bar

for all three retired names, the live qualified-reference representation has
passing parser/emitter/identity evidence, self-host and Store focused checks
pass on the same commit, and the final tracked-tree search is empty. Commit
only the enumerated source, guard, and direct-test paths, land through
`safe-push --to main`, fast-forward `beagle:main`, and reap the lane and
branch. Do not modify the pre-existing dirty scaffold lane during landing.

## Rollback

Keep both bridge helpers until the checker migration and its focused tests are
green. If checker parity fails, revert only the checker migration and retain
the bridge. If the deletion or guard change fails, revert that final commit as
one unit; restore the last green lane from its clean parent rather than
resetting the shared dirty lane.

## Final deletion and absence proof

After the live checker caller has migrated, delete the complete bridge/scaffold
surface and direct tests. Run a tracked-tree token search for the retired symbol
accessor and both structural-name bridges; every result must be absent. Then run
the qualified-reference scaffold guard one final time and its owning focused
